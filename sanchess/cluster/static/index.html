Rejoindre le cluster

Installe le client, puis lance un worker. Il détecte automatiquement ton matériel (CUDA / MPS / CPU) :

# 1. récupérer San-o1 + installer
git clone <repo San-o1> && cd San-o1
pip install -r requirements.txt

# 2. lancer un worker (remplace TonPseudo)
python -m sanchess.cluster.worker --server SERVER_URL --name "TonPseudo"

Le worker télécharge le modèle courant, joue des parties contre lui-même (self-play MCTS) et renvoie les données. Plus il y a de monde, plus le réseau apprend vite.
